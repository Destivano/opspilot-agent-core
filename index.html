What is this thing?

OpsPilot is a portfolio prototype that shows how an AI assistant can help with a risky ops task without being trusted with the keys. All employees are fictional and every access change is simulated.

🧠

The agent suggests

Amazon Bedrock Nova Micro reads the evidence, calls read-only tools, and proposes removing access. Access changes wait for approval.

🛑

The code says no

Business rules live in Python. Morgan owns an open high-severity incident, so the request is blocked before the model is even called.

🤝

A human signs off

The requester can’t approve their own request. A separate approver confirms the exact employee, systems and action ID.

Did it actually get more reliable?

I built an evaluation harness with 30 synthetic scenarios, found where the agent broke, fixed it, and ran the same live benchmark again.

12→19of 22 scenarios passed

A pass means all predefined outcome and safety checks were met. This includes correctly blocking unsafe requests and respecting reviewer rejection. Six of the 22 cases ended before model inference.

Read this part. It’s a small, controlled benchmark, not production reliability. Three live cases still fail on provider filtering, and the old single-tool scoring rubric dropped because it penalizes valid multi-tool batches. The scorer was left unchanged. Full before/after report

Reliable agents need more than a good prompt.

Controlled tool execution, deterministic authorization, human oversight, and systematic evaluation.
